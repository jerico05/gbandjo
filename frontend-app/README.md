# Gbandjo — Application marketplace (consommateur & commerçant)

React + Vite + TypeScript + Tailwind CSS 4.

## Démarrage

```bash
pnpm install
cp .env.example .env
pnpm dev
```

## Structure (extrait)

- `src/components/ui/` — design system (Button, Container, Badge)
- `src/components/layout/` — header / footer publics
- `src/components/marketing/` — sections landing
- `src/data/mock/` — jeux de données remplaçables
- `src/lib/services/` — appels API + repli mock

Voir `docs/frontend-architecture.md` à la racine du dépôt.
